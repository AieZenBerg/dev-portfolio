# Dev Portfolio

Portfolio développeur personnalisable en HTML, CSS et JavaScript.

## État du projet

Projet de démarrage. La base web est fournie pour être développée et personnalisée.

## Fonctionnalités

Mise en page responsive, cartes de projets et changement de thème.

## Démarrage

Ouvrir `index.html` dans un navigateur récent. Pour un serveur local, depuis le dossier du projet :

```sh
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000.

## Structure

- `index.html` : interface et contenu.
- `styles.css` : styles responsive.
- `app.js` : interactions JavaScript.

## Prochaines étapes

- Personnaliser le profil et les projets.
- Ajouter des liens vers les réalisations.
- Ajouter un formulaire de contact avec un service adapté.
